# Luma — Displaylicht

Eine responsive Demo-Oberfläche zum Steuern des Displaylichts.

`index.html` im Browser öffnen. Die App ist bis zur einmaligen Freischaltung für CHF 49 gesperrt. Die Freischaltung ist eine lokale Demo: Es wird keine echte Zahlung ausgelöst, und es ist kein Display angeschlossen. Der Freischaltstatus wird im lokalen Browser gespeichert.
